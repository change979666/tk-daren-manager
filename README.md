# TK达人管理系统

A Windows desktop utility for importing TikTok creator lists from Excel/CSV, deduplicating usernames against persistent history, recording first-export times, and exporting batches of 50 usernames.

用于整理 TK 达人表格数据的桌面工具，支持批量导入表格文件、自动检测重复的达人用户名，并按照每个文件 50 个达人的规格导出数据。

## 功能特点

- **批量导入表格文件**：支持 Excel（.xlsx / .xls）和 CSV 格式
- **仅显示当前会话导入的数据**：每次启动程序只显示本次导入的数据
- **后台检测重复项**：自动与历史数据比对，标记重复的达人用户名
- **记录首次导出时间**：在第一次导出时记录达人用户名的导出时间
- **灵活的清除选项**：支持清除全部数据或仅清除最近导入的数据
- **精简导出**：可以选择只导出用户名字段，满足不同场景需求
- **自动分批导出**：按照每个文件 50 个达人用户名的规格自动分批导出
- **历史记录管理**：可查看和管理历史记录，便于数据追踪
- **新增持久化配置**：配置和历史数据保存在用户主目录下，避免程序移动导致的数据丢失

## 安装方式

### 方式一：直接使用打包好的 exe 程序（推荐）

1. 从发布页面下载 `TK达人管理系统.exe` 文件
2. 双击运行即可，无需安装 Python 或其他依赖

### 方式二：从源码安装

1. 安装 Python 3.6 或更高版本
2. 克隆或下载本项目代码
3. 安装依赖包：

```bash
pip install -r requirements.txt
```

4. 运行程序：

```bash
python main.py
```

## 使用方法

1. 运行程序（双击 exe 文件或通过 Python 运行）
2. 主要功能：
   - **导入表格**：点击"导入表格"按钮导入 TK 达人表格文件（支持 Excel 和 CSV 格式）
   - **自动检测重复**：程序会自动检测并标记重复的达人用户名
   - **删除重复项**：点击"删除重复项"按钮可以删除重复的达人用户名
   - **导出表格**：点击"导出表格"按钮将数据导出到 Excel 或 CSV 文件
   - **清除数据**：提供"清除所有数据"和"清除本次导入"两个选项
   - **查看历史记录**：通过"数据管理"菜单可以查看历史记录统计

## 数据管理机制

- **当前会话数据**：程序只显示和导出当前会话导入的数据
- **历史记录**：自动保存所有历史数据，但不在界面显示，仅用于重复检测
- **重复检测逻辑**：新导入的数据会与历史记录进行对比，检测重复项
- **数据持久化**：程序关闭后，历史数据会被保存，下次启动时自动加载

## 导入文件格式要求

程序会自动尝试识别表格中的达人用户名列，优先识别以下情况：
- 列名包含"用户名"或"达人"的列
- 如果没有找到匹配的列名，将使用每行的第一个非空值作为达人用户名

## CSV 文件支持

程序支持导入和导出 CSV 格式的文件：
- 导入时会自动尝试不同的编码方式（UTF-8, GB18030, Latin-1）来处理中文
- 导出 CSV 文件时使用 UTF-8 编码并添加 BOM 标记，以确保 Excel 正确显示中文

## 时间记录逻辑

- 导入数据时不记录时间，表格中会显示"尚未记录"
- 在第一次导出数据时，系统会为所有未记录时间的达人用户名设置导出时的时间
- 时间记录保存在历史数据中，可用于后续重复检测

## 注意事项与数据存储

- 导入大量数据时可能需要一定的处理时间，请耐心等待
- 每次启动程序只会显示当前导入的数据，历史数据仅用于重复检测
- 导出的文件会自动添加日期时间标识，避免文件覆盖
- **数据存储位置**：所有配置和历史数据都保存在用户主目录下的 `.tk_manager` 文件夹中
- 如果要备份所有历史记录，可以复制整个 `.tk_manager` 文件夹
- 要完全清除所有历史记录，可以使用"数据管理"菜单中的"清除历史记录"功能，或手动删除 `tk_records.dat` 文件
